## Описание
Создана роль host, которая выполняет установку пакетов cri-o, kubelet, kubeadm, kubectl. Также созданы тесты, которые проверяют версии установленных пакетов и наличие служб после установки.

## Особенности реализации
1. Создано два теста. Один проверяет версии установленных пакетов, другой проверяет наличие служб после установки
2. Используется allure для генерации отчетов тестирования. Отчеты сохраняются в /tmp/allure-results
3. Ввиду невозможности скачать пакеты из репозиториев cri-o и kubernetes, был развернут одной командой репозиторий на мастере (его в целом кто угодно может использовать). Ключи не создавал. Можно было и nfs использовать, но это потребовало бы доп. установку пакета на всех машинах и сервера на мастере, создание еще одной службы на мастере и чуть больше написать в плейбуке
4. Переменные не используются (изначально предполагалось использовать для указания версий пакетов, но в репозитории итак только нужные версии). Сторонние модули также не использовались
5. В файлах роли изменен только tasks/main.yml
6. файлы молекулы лежат в collections/ansible_collections/v_neyanin/kuber/roles/host
7. Плейбук вызывает роль без каких-либо параметров или переменных
8. Создан файл конфигурации ansible.cfg, а также collections/ansible_collections/v_neyanin/kuber/roles/host/molecule/tests/pytest.ini
## Quickstart
1. Подготовить python-окружение, используя файл requirements. (**ПРОШУ ОБРАТИТЬ ВНИМАНИЕ, ЧТО ИСПОЛЬЗУЕТСЯ ТАКЖЕ ALLURE**)
2. **Тестирование** (перейти в collections/ansible_collections/v_neyanin/kuber/roles/host)
    ```
    molecule create
    molecule converge
    molecule verify
    cd / && allure serve /tmp/allure-results
    molecule destroy
    ```
    **Запуск на хостах**
    ```
    ansible-playbook prepare_for_kuber.yml
    ```
